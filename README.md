# Carta de Smith

Presentación universitaria interactiva sobre la Carta de Smith: análisis de impedancias, coeficiente de reflexión y adaptación en líneas de transmisión.

Integrantes: Sharon Mawenzy Martínez · Brayan Stiven Correa · Fabián Steven Vargas

- [`presentacion/`](presentacion/): presentación web (23 diapositivas). Abre `presentacion/index.html` en Chrome o Edge. Instrucciones en [presentacion/README.md](presentacion/README.md).
- [`CARTA.PY`](CARTA.PY): análisis de la línea microstrip en FR4 (modelo teórico ideal, o un archivo Touchstone exportado de HFSS si existe).
- [`analisis_microstrip.png`](analisis_microstrip.png): figura generada por `CARTA.PY`.
